# MandaNica

**De aquí para vos.**

Plataforma integral de delivery, comercio y transporte para Nicaragua.

## Servicios
- Restaurantes y comida
- Supermercados y pulperías
- Farmacias
- Tiendas y comercios
- Mandados y paquetería
- Compras generales
- Transporte de pasajeros
- Transporte de mercancías y carga

## Mercado inicial
Managua y Ciudad Sandino, Nicaragua.

## Módulos
- Clientes
- Comercios
- Repartidores
- Conductores
- Administración

## Objetivo
Construir una plataforma segura, conectada y escalable para Nicaragua.
